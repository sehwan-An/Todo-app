# PRD - Todo App (초안)

> 원본: docs/IDEA.md
> 상태: 초안. "미정" 표시 항목은 결정 후 갱신한다.

## 1. 목표
- 혼자 쓰는 간단한 할 일 목록 웹 앱을 만든다.
- 화면 → API → DB → 배포 순서로 단계별로 만들며 웹 개발 전 과정을 익힌다.
- MVP 기능(F-01 ~ F-05)을 모두 갖춘 상태로 v1.0을 배포한다.

## 2. 대상 사용자
- 자신의 할 일을 가볍게 기록하고 관리하려는 **개인 사용자 1명** (본인)
- 로그인이 없으므로 여러 사용자를 구분하지 않는다.

## 3. 기능 목록

| ID | 기능 | 설명 | 도입 버전 |
|---|---|---|---|
| F-01 | 할 일 추가 | 제목을 입력해 할 일을 추가한다. 제목은 필수, 1~100자. (아래 "제목 규칙") | v0.1 |
| F-02 | 할 일 목록 보기 | 전체 할 일을 최신순(만든 시간 기준)으로 보여준다. | v0.1 |
| F-03 | 완료/미완료 전환 | 체크박스로 할 일의 완료 상태를 바꾼다. | v0.1 |
| F-04 | 할 일 삭제 | 할 일을 목록에서 지운다. | v0.1 |
| F-05 | 데이터 유지 | 새로고침해도 할 일이 사라지지 않는다. | v0.3 (DB 저장 시 완전 충족) |

- MVP = F-01 ~ F-05

**제목 규칙**
- 앞뒤 공백을 지운 뒤 검사하고, 지운 값으로 저장한다. (예: `"  우유 사기  "` → `"우유 사기"`)
- 공백을 지운 뒤 1자 이상, 100자 이하여야 한다. 공백만 입력하면 0자가 되어 거부된다.
- 글자 수는 유니코드 문자(코드 포인트) 단위로 센다. 한글 한 글자, "👍" 같은 이모지 하나는 1자다.
  - 단, 피부색 등이 합쳐진 이모지(예: 👍🏽)는 2자 이상으로 셀 수 있다.
- F-05 참고: v0.1(브라우저 메모리)은 새로고침 시, v0.2(서버 메모리)는 서버 재시작 시 데이터가 사라진다.

## 4. 사용자 스토리

| ID | 기능 | 사용자 스토리 |
|---|---|---|
| US-01 | F-01 | 사용자로서, 떠오른 할 일을 바로 적어두고 싶다. 잊어버리지 않도록. |
| US-02 | F-01 | 사용자로서, 제목 없이 추가하거나 너무 긴 제목을 넣으면 알림을 받고 싶다. 잘못된 할 일이 쌓이지 않도록. |
| US-03 | F-02 | 사용자로서, 최근에 추가한 할 일을 맨 위에서 보고 싶다. 새 할 일을 바로 확인하도록. |
| US-04 | F-03 | 사용자로서, 끝낸 일을 체크하고 싶다. 무엇을 끝냈는지 구분하도록. |
| US-05 | F-03 | 사용자로서, 잘못 체크한 일을 다시 미완료로 돌리고 싶다. 실수를 바로잡도록. |
| US-06 | F-04 | 사용자로서, 필요 없어진 할 일을 지우고 싶다. 목록을 깔끔하게 유지하도록. |
| US-07 | F-05 | 사용자로서, 페이지를 새로고침하거나 다시 열어도 할 일이 남아 있길 원한다. 다시 입력하지 않도록. |

## 5. 범위 밖
- 로그인 / 회원가입
- 공유 (다른 사람과 목록 함께 쓰기)
- 알림
- 마감일
- 카테고리
- 위에 없는 기능이라도 기능 목록(3장)에 없으면 범위 밖으로 본다.

## 6. 성공 기준
- **기능**: F-01 ~ F-05가 모두 동작한다.
  - 1~100자 제목은 추가되고, 빈 제목, 공백만 있는 제목, 101자 이상 제목은 거부된다.
  - 앞뒤 공백은 지워진 채로 저장된다.
  - 목록이 최신순으로 표시된다.
  - 체크박스로 완료 ↔ 미완료가 양방향으로 바뀐다.
  - 삭제한 할 일은 목록에서 사라진다.
  - 새로고침 후, 그리고 서버 재시작 후에도 데이터가 그대로 남아 있다. (v0.3 이후)
- **버전**: 로드맵의 각 버전(v0.1 ~ v1.0)이 위 기준 중 해당 범위를 만족한 뒤 다음 버전으로 넘어간다.
- **품질**: 테스트(docs/TEST_CASES.md 기준)가 모두 통과한다.
- **배포**: v1.0에서 배포된 URL로 접속해 MVP 기능을 모두 사용할 수 있다.

## 7. 미정 사항
- 정렬: 완료한 할 일을 제자리에 둘지, 아래로 내릴지
- 삭제: 확인 창을 띄울지
- 빈 목록일 때 보여줄 안내 문구
- F-05: v0.1에서 localStorage로 미리 충족할지
